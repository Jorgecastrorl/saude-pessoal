Política de privacidade

Aplicativo "Saúde pessoal" — atualizada em 26/11/2026.

Quais dados são acessados

Somente com autorização expressa do titular, e apenas em modo de leitura: perfil e configurações, atividade física, sono, medidas de saúde e nutrição da conta Google Health/Fitbit do próprio titular.

Como os dados são usados

Para consulta e análise pessoal do próprio titular (tendências de sono, atividade e frequência cardíaca). O aplicativo não grava, altera nem apaga dados na conta Google.

Onde os dados ficam

O token de acesso e os dados consultados ficam armazenados apenas no computador de quem autorizou. Não existe servidor do aplicativo; nada é enviado a terceiros, vendido ou usado para publicidade.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/connections. Ao revogar, o aplicativo perde imediatamente o acesso aos dados.
